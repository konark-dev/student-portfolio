Existing Approach

Students currently use different platforms for different purposes:

- LinkedIn for professional identity
- GitHub for technical work
- Portfolio websites for presenting projects
- Other platforms for certificates, achievements, and academic information

Observed Gap

Student information can be spread across multiple platforms.

A student may have:

- Education information in one place
- Projects on GitHub
- Certificates in cloud storage
- Professional information on LinkedIn
- Achievements somewhere else

This can make it difficult to maintain and present everything as one complete student profile.

Our Opportunity

Our platform can provide one place where students can organize and present:

- Personal information
- Education
- Skills
- Projects
- Certifications
- Achievements
- Professional links

The goal of V1 is not to replace platforms such as LinkedIn or GitHub, but to provide a simple centralized student profile.

V1 Focus

For the first version, we will focus on:

1. Creating a student profile
2. Adding education information
3. Adding skills
4. Adding projects
5. Adding achievements/certifications
6. Displaying the information professionally
7. Sharing the profile

Out of Scope for V1

- Advanced AI features
- Complex networking
- Job marketplace
- Advanced analytics
- Complex recommendation systems
- Large-scale institutional features
