1. LinkedIn

Purpose:
Professional networking and building an online professional identity. It is used for jobs, internships, networking, and showcasing education, skills, and experience.

Important features:

Professional profile
Education
Skills
Experience
Projects/media
Connections
Job/internship opportunities
Posts and professional content

What we can learn from it:
A professional profile should present a student's background and skills clearly, while also making the profile useful for career opportunities.





2. GitHub

Purpose:
Showcase software development work, repositories, contributions, and technical activity.

Important features:

Profile
Bio
Profile README
Repositories
Contributions
Projects/code
Developer activity

What we can learn from it:
A profile becomes more valuable when it shows evidence of skills, rather than only listing them.





3. Notion

Purpose:
Create flexible pages that can be published as websites, including resumes, portfolios, and personal websites.

Important features:

Custom pages
Portfolio templates
Resume templates
Projects
Media/embeds
Public sharing
Website publishing
Customization

What we can learn from it:
Giving users templates and simple customization makes creating a professional online presence easier without requiring them to build a website from scratch.





4. Showcase

Purpose:
A student-owned digital portfolio for collecting and sharing work.

Important features:

Student profile
Upload documents/images
Link external work
Connect Google Drive/OneDrive
Public portfolio URL
Student-controlled content

What we can learn from it:
A student-focused platform can focus specifically on showing actual student work, not just professional information.
