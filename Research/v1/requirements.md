---- Functional Requirements

* P0 — Must Have

- FR-001: Student can create an account.
- FR-002: Student can create and edit their profile.
- FR-003: Student can add education details.
- FR-004: Student can add skills.
- FR-005: Student can add projects.
- FR-006: Student can add certifications and achievements.
- FR-007: Student can add professional links.
- FR-008: Student can view their complete profile.
- FR-009: Student has a shareable public profile.

* P1 — High Value

- FR-101: Student can customize the appearance of their profile.
- FR-102: Student can add project links such as GitHub or live demos.
- FR-103: Student can upload a profile picture.

* P2 — Later

- FR-201: AI-assisted profile creation.
- FR-202: AI suggestions for improving the profile.
- FR-203: Profile analytics.

---- Non-Functional Requirements

- Responsive on desktop and mobile.
- User data must be protected.
- Users can only edit their own profile.
- API responses should be predictable.
- The application should remain usable if AI features are unavailable.

* MVP

The V1 MVP consists of:

1. Authentication
2. Student profile
3. Education
4. Skills
5. Projects
6. Certifications/achievements
7. Professional links
8. Public profile

* Out of Scope

- Job marketplace
- Social networking
- Messaging
- Complex recommendation systems
- Advanced analytics
